Ferimento (no controle manual)

Atadura: 3 panos (perna machucada). Tala: 3 panos e 2 madeiras (serve também para fratura). Kit médico serve para os dois.

Corda (no controle manual)

Borda verde: ele consegue usar. Vermelha: não dá. Amarela: passa por baixo. Para controlar: WASD ou setas, Espaço pula ou agarra, C abaixa. Pendurado: W sobe, S solta, A/D anda de lado.

A seta laranja é para onde você manda ir. Os pontinhos são o caminho que o personagem fez.

O que ele carrega

Arraste o personagem para girar. Deixe a velocidade baixa para olhar cada passo.
